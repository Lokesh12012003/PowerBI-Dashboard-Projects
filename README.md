##  🎬 Netflix Dashboard – Power BI
📌 Project Overview

This project analyzes Netflix movies and TV shows using an interactive dashboard built with Microsoft Power BI. It explores content distribution, genres, release trends, and country-wise availability to identify meaningful insights.

## 🛠️ Tools & Technologies
Microsoft Power BI
Power Query
DAX (Data Analysis Expressions)
Data Cleaning & Transformation
Data Visualization
## 📊 Key Insights
Total number of movies and TV shows available
Movies vs. TV shows distribution
Popular genres and content categories
Content trends by release year
Country-wise content distribution
Ratings and content classification analysis

## 🚀 How to View the Dashboard
Download the Netflix_Dashboard.pbix file from this repository.

Explore the dashboard using its interactive visuals and filters.
